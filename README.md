# Mittivoy IT-поддержка — дашборд

Заявки IT-поддержки Mittivoy по филиалам: сколько, о чём, как быстро решаем.

Сайт: https://tttmardon-ui.github.io/mittivoy-dashboard/

Цифры берутся из ClickUp (список MIT-ITSM) и базы ИИ-агента поддержки. Агент пересчитывает их
каждые 10 минут и сам обновляет `stats.json` в этом репозитории — в зашифрованном виде (AES-256, пароль знает IT-поддержка). Только сводные числа:
имён сотрудников, текстов заявок и ссылок на группы здесь нет.
